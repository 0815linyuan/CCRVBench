# CCRV-Bench: Constrained Causal Reasoning in Vision

This repository contains the evaluation pipeline and benchmark datasets for our paper on evaluating the causal reasoning robustness of Vision-Language Models (VLMs) under strict constraints.

## 1. Dataset Overview

Our benchmark is built upon 100 manually curated, high-quality images. Based on these images, we manually annotated 800 foundational causal questions (Baseline). We then programmatically applied adversarial constraints (Y1-Y4) to generate the constrained question set.

The finalized datasets are provided in the root directory:
* **`benchmark_with_rubrics_top100.json`**: The Unconstrained Baseline dataset (800 manually curated questions) along with their evaluation rubrics.
* **`benchmark_main_set_with_rubrics_top100.json`**: The Constrained Main dataset (3200 questions generated by applying Y1-Y4 constraints to the baseline) along with their evaluation rubrics.
* **`VG_images_test/`**: The directory containing the 100 original image files used for the benchmark.

## 2. File Directory & Code Description

The evaluation pipeline is strictly divided into dataset generation, VLM inference, LLM-as-a-judge scoring, and quantitative analysis.

### Utility & Configuration
* **`config.py`**: Global configuration file (API keys should be configured via a `.env` file).
* **`y4_word_normalize.py`**: A programmatic judge script used strictly for evaluating the $Y_4$ (Compression Bottleneck) constraint by normalizing and counting words accurately.

### Step 1: Constraint Generation (Optional / For Reference)
*These scripts demonstrate how the constraints and rubrics were applied to the manual baseline.*
* **`step1b_generate_main_set.py`**: Applies Y1-Y4 constraints to the manual baseline questions.
* **`step1c_generate_main_set_rubrics.py`**: Generates evaluation rubrics for the newly constrained questions.

### Step 2: VLM Inference
*Scripts to prompt evaluated VLMs to answer the benchmark questions.*
* **`step2_vlm_inference_baseline.py`**: Runs inference on the unconstrained Baseline set.
* **`step2_vlm_inference_main_set.py`**: Runs inference on the Constrained Main set.
* **`step2_vlm_inference_baseline_cot.py`**: Runs inference on the baseline set using Chain-of-Thought (CoT) prompting for ablation studies.
* *(Note: Raw output logs from models are stored in the `model_outputs/` directory.)*

### Step 3: LLM-as-a-Judge Evaluation
*Scripts that use GPT-5.1 to evaluate VLM answers based on the DCR (Causal) and CSR (Constraint) rubrics.*
* **`step3_judge_scoring_baseline.py`**: Scores the unconstrained Baseline answers.
* **`step3_judge_main_set.py`**: Scores the Constrained Main set answers (incorporating programmatic checks for $Y_4$).
* **`step3_judge_scoring_baseline_cot.py`**: Scores the CoT ablation answers.

### Step 4: Quantitative Analysis
*Scripts to aggregate scores, calculate Causal Degradation Index (CDI), and generate reports.*
* **`step4_analyze_results_baseline.py`**: Calculates the performance metrics for the Baseline set.
* **`step4_analyze_main_set.py`**: Calculates effective DCR (eDCR) and eCDI for the Constrained Main set.
* **`analyze_cot_ablation.py`**: Analyzes the performance differences when CoT is applied.
* *(Note: Statistical summaries and text reports are exported to the `analysis_results/` directory.)*

## 3. Execution Order

To fully reproduce the evaluation results for a given model, execute the scripts in the following order:
1. `python step2_vlm_inference_main_set.py` (Generate answers)
2. `python step3_judge_main_set.py` (Judge answers)
3. `python step4_analyze_main_set.py` (Export metrics)

*(Repeat the equivalent `step2` -> `step3` -> `step4` sequence for the Baseline or CoT ablation sets as needed.)*
